# PokeDNA status page on the tailnet

The feature matrix (`docs/feature-matrix.html`, generated by `tools/gen_matrix_html.py`) is
also written to `docs/site/index.html`, a folder that holds ONLY the page — `docs/` itself
carries fused ROM builds and analysis dumps and must never be served.

**URL (tailnet only, HTTP on purpose — same reasons as the Thesis pages: certs are off in the
admin console, WireGuard already encrypts):** `http://YOUR-HOST.YOUR-TAILNET.ts.net:8090/`

Set up 2026-09-04 (additive: the Thesis proxies on :80 and :8080 are untouched):

    /usr/local/bin/python3 -m http.server 8770 --bind 127.0.0.1 --directory docs/site   # loopback only
    tailscale serve --bg --http=8090 http://127.0.0.1:8770                               # tailnet -> loopback

The loopback server was started with `nohup` and dies on reboot; the Tailscale proxy persists.
To make the server survive reboots (needs Guy — agents cannot run launchctl):

    cp tools/hosting/com.guy.pokedna-site.plist ~/Library/LaunchAgents/
    launchctl load ~/Library/LaunchAgents/com.guy.pokedna-site.plist

Refresh the page after editing `docs/FEATURE-MATRIX.md`:

    /usr/local/bin/python3 tools/gen_matrix_html.py      # (the system python3 lacks `markdown`)

Teardown: `tailscale serve --http=8090 off`, `pkill -f 'http.server 8770'`, and if installed
`launchctl unload ~/Library/LaunchAgents/com.guy.pokedna-site.plist && rm` that file.
